# 2.10 SDK 补丁

SDK 组件补丁针对 K3 使用的 SpacemiT Robot SDK（`spacemit_robot`）源码，用于 K1 平台适配及相关功能修正。BROS、独立软件包和外部参考工程的补丁另列于下表。补丁适用范围取决于组件源码版本。

下文汇总补丁用途、下载地址和单独应用方法。按使用的组件选择补丁；各功能章节提供对应步骤。

## 2. 应用方法

SDK 补丁命令默认在 `spacemit_robot` 根目录执行。下载所需补丁，应用到对应组件后，再按功能章节重新编译。

安装补丁工具：

```bash
sudo apt install -y wget patch
```

BROS 补丁直接修改复制后的 Python 文件、配置或脚本，无需构建工作空间。Python 包通过 `PYTHONPATH` 加载，参数文件通过启动参数指定，安装脚本直接运行。

同一份 SDK 中，每个补丁只需应用一次。若源码已包含该修改，可跳过对应步骤；同时使用两个 Omni Agent 补丁时，按 ASR 后端配置、LLM 启动等待的顺序应用。

### 2.1 视觉推理线程

先检查源码是否包含 TCM 核数预算实现：

```bash
git -C components/model_zoo/vision grep -n 'plan_session_configs' -- src/core/cpp/vision_session_config.cpp
```

若找到该函数（例如提交 `30647da`），直接编译，不应用本节旧补丁。此实现通过 `libspine_tcm.so.3` 查询可用 AI 核数，并为模型的 SpaceMIT EP 会话分配线程；保留示例配置即可。该库由 `spacemit-tcm` 提供，随 `spacemit-onnxruntime` 的依赖安装。

下面的适配版补丁基于 Vision 源码提交 `c7b78ae122cab8db15b8ea39a41cc22e59390f74` 整理。没有上述实现的旧版源码，下载补丁并先检查是否适用：

```bash
wget -O /tmp/vision-threads.patch \
    https://raw.githubusercontent.com/zyi952694-crypto/K1/annyi_dev/02-%E5%BF%AB%E9%80%9F%E5%85%A5%E9%97%A8/assets/patches/vision-threads-c7b78ae.patch && \
git -C components/model_zoo/vision apply --check /tmp/vision-threads.patch && \
git -C components/model_zoo/vision apply /tmp/vision-threads.patch
```

若检查失败，按第 3 节确认是否已包含该修改或源码版本不匹配，不要强制应用。

### 2.4 本地 LLM 启动等待

本补丁与 2.3 节基于同一版 Omni Agent 源码。它等待 LLM 的 `/health` 返回成功，并让父进程按 `llm.startup_timeout` 留出足够的启动时间；同时使用两份补丁时，先应用 2.3 节，再应用本节。

```bash
wget -O /tmp/omni-llm-startup.patch \
    https://raw.githubusercontent.com/zyi952694-crypto/K1/annyi_dev/02-%E5%BF%AB%E9%80%9F%E5%85%A5%E9%97%A8/assets/patches/0002-omni-llm-health-febbeccf.patch && \
```

### 2.11 OCR 图像发布

```bash
BROS_PATCH_ROOT="$HOME/bros-patches"
mkdir -p "$BROS_PATCH_ROOT/python" && \
cp -a /opt/bros/humble/lib/python3.12/site-packages/jobot_ppocr_py \
    "$BROS_PATCH_ROOT/python/" && \
wget -O "$BROS_PATCH_ROOT/bros-ocr-image-publisher.patch" \
    https://archive.spacemit.com/ros2/k1_sdk/patches/bros/jobot_ppocr_py/bros-ocr-image-publisher.patch && \
patch -d "$BROS_PATCH_ROOT/python" -p1 --batch --fuzz=0 --forward --dry-run \
    < "$BROS_PATCH_ROOT/bros-ocr-image-publisher.patch" && \
patch -d "$BROS_PATCH_ROOT/python" -p1 --batch --fuzz=0 --forward \
    < "$BROS_PATCH_ROOT/bros-ocr-image-publisher.patch"
```

运行节点的每个终端先加载 BROS 环境，再添加 Python 包路径：

```bash
source /opt/bros/humble/setup.bash
export PYTHONPATH="$HOME/bros-patches/python${PYTHONPATH:+:$PYTHONPATH}"
```

后续启动步骤见[对应章节](../05-机器人开发/5.2-机器感知/5.2.12-OCR.md)。

## 3. 应用失败时的处理

`git apply` 提示 `patch does not apply` 时，先检查补丁是否已应用。以视觉组件为例：

```bash
git -C components/model_zoo/vision apply --reverse --check /tmp/vision-threads.patch
```

反向检查通过时，跳过已应用的补丁。正向与反向检查都失败时，先检查源码是否已有替代实现，例如 2.1 中的 TCM 核数预算，再对照补丁涉及的文件检查版本和本地修改。
