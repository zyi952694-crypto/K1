# 2.10 SDK 补丁

SDK 组件补丁针对 K3 使用的 SpacemiT Robot SDK（`spacemit_robot`）源码，用于 K1 平台适配及相关功能修正。BROS/RDK、独立软件包和外部参考工程的补丁另列于下表。补丁适用范围取决于组件源码版本。

下文汇总补丁用途、下载地址和单独应用方法。按使用的组件选择补丁，并在编译前应用；各功能章节提供对应步骤。

## 2. 应用方法

SDK 补丁命令默认在 `spacemit_robot` 根目录执行。下载所需补丁，应用到对应组件后，再按功能章节重新编译。

RDK 包补丁需要配套源码。将 `RDK_ROOT` 设为本机已有的源码目录；LLM 安装脚本也可直接复制已安装脚本后应用补丁，见 2.17。

```bash
RDK_ROOT=/path/to/rdk
```

同一份 SDK 中，每个补丁只需应用一次。若源码已包含该修改，可跳过对应步骤；同时使用两个 Omni Agent 补丁时，按 ASR 后端配置、LLM 启动等待的顺序应用。

### 2.1 视觉推理线程

先检查源码是否包含 TCM 核数预算实现：

```bash
git -C components/model_zoo/vision grep -n 'plan_session_configs' -- src/core/cpp/vision_session_config.cpp
```

若找到该函数（例如提交 `30647da`），直接编译，不应用本节旧补丁。此实现通过 `libspine_tcm.so.3` 查询可用 AI 核数，并为模型的 SpaceMIT EP 会话分配线程；保留示例配置即可。该库由 `spacemit-tcm` 提供，随 `spacemit-onnxruntime` 的依赖安装。

没有上述实现的旧版源码，下载补丁并先检查是否适用：

```bash
wget -O /tmp/vision-threads.patch \
    https://archive.spacemit.com/ros2/k1_sdk/patches/components/model_zoo/vision/0001-feat-vision-clamp-SpaceMIT-EP-threads-to-available-A.patch && \
git -C components/model_zoo/vision apply --check /tmp/vision-threads.patch && \
git -C components/model_zoo/vision apply /tmp/vision-threads.patch
```

若检查失败，按第 3 节确认是否已包含该修改或源码版本不匹配，不要强制应用。

## 3. 应用失败时的处理

`git apply` 提示 `patch does not apply` 时，先检查补丁是否已应用。以视觉组件为例：

```bash
git -C components/model_zoo/vision apply --reverse --check /tmp/vision-threads.patch
```

反向检查通过时，跳过已应用的补丁。正向与反向检查都失败时，先检查源码是否已有替代实现，例如 2.1 中的 TCM 核数预算，再对照补丁涉及的文件检查版本和本地修改。
