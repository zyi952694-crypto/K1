# 6.5.5 AI Robot安装

本节介绍 RDK 运行环境的安装。ROS2_LXQT 已预装 ROS 2 和 RDK，可使用已有环境。

使用 Bianbu Minimal、LXQt、GNOME 通用固件时，先按 [6.5.1 ROS2 安装](6.5.1-ROS2安装.md)准备 ROS 2，再执行以下命令安装 RDK 运行环境：

```bash
sudo apt update && sudo apt install -y wget && cd ~
wget https://archive.spacemit.com/ros2/bros.tar.gz
cd /opt && sudo tar xzvf ~/bros.tar.gz
```

解压完成后，RDK 的二进制程序位于 `/opt/bros`。运行前，在终端依次执行 `source /opt/ros/humble/setup.bash` 和 `source /opt/bros/humble/setup.bash`，加载 ROS 2 与 RDK 环境。
