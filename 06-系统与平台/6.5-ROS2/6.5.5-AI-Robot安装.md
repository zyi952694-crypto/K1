# 6.5.5 AI Robot安装

BROS 提供机器人感知、导航和人机交互等 ROS 2 功能包。先按 [6.5.1 ROS2 安装](6.5.1-ROS2安装.md)准备 ROS 2，再下载并安装 BROS：

```bash
sudo apt update
sudo apt install -y wget patch
wget -O ~/bros.tar.gz https://archive.spacemit.com/ros2/bros.tar.gz && \
sudo tar -xzf ~/bros.tar.gz -C /opt
```

加载运行环境：

```bash
source /opt/ros/humble/setup.bash
source /opt/bros/humble/setup.bash
```

功能包位于 `/opt/bros/humble`，常用文件目录如下：

```text
/opt/bros/humble/
├── lib/
│   ├── <功能包名>/                  # 节点程序与入口脚本
│   └── python3.12/site-packages/    # Python 功能包源码
└── share/<功能包名>/
    ├── launch/                     # 启动文件
    ├── config/                     # 参数配置
    └── ...                         # 模型配置、示例素材等资源
```

需要修改 Python 功能包或配置时，按[2.10 SDK 补丁](../../02-快速入门/2.10-SDK补丁.md)及对应功能章节复制文件、应用补丁，再加载修改后的文件。BROS 安装包不包含完整的 C++ 源码和构建工作空间。
