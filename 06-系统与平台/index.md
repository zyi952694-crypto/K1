## K1 暂不提供的章节

K3 SDK 文档中的以下章节，因 K1 硬件或内核条件不满足，K1 文档暂不提供：

| K3 章节 | K1 现状 |
| --- | --- |
| 6.1.2 DMA | K1 内核无 `/dev/me_dma` 驱动 |
| 6.1.3 SHM | K1 无对应内核模块 |
| 6.2.8 5G | MUSE Pi Pro 无 5G 模组 |
| 6.2.11 电源管理 | MUSE Pi Pro 无板载 CW2015 电量计 / IP2317 充电芯片 |
| 6.4 实时系统（实时 Linux / RTOS） | K1 不支持当前实时内核补丁路径 |

电机驱动（6.2.9）正在验证：UART M0603C、RS485 M0601C 已通过；CAN DM-J4310 受当前 DTB 限制尚未跑通，完成后补充。
