# 3.2.4 环形麦克风使用说明

> **说明**
>
> 旧版 K1 文档基于 Demo Zoo（`spacemit-demo` 仓库 `examples/NLP/04_asr_demo_db.py`）。Demo Zoo 已不再维护，本节改用 K3 SDK 的 audio 组件和 Model Zoo ASR 组件；声源定位使用 SDK 的 audio_process 组件，见 [6.3.3 音频算法](6.3.3-音频算法.md)。

## 前置条件

1. 按 [3.2.1 麦克风硬件调试说明](6.3.10-麦克风硬件调试说明.md) 连接麦克风，并把当前用户加入 `audio` 组。
2. 按 [1.6 构建编译](../../02-快速入门/2.3-构建编译.md) 获取 SDK（`spacemit_robot`）并完成基础环境配置。以下命令以 SDK 位于 `~/spacemit_robot` 为例。

## 编译音频与 ASR 组件

本节使用 SDK 自带的 audio 组件（`components/multimedia/audio`）采集音频，并使用 Model Zoo 中的 ASR 组件（`components/model_zoo/asr`）做识别验证，不修改 SDK 源码。

```bash
sudo apt install portaudio19-dev libasound2-dev libsndfile1-dev \
    libsamplerate0-dev libfftw3-dev libcurl4-openssl-dev alsa-utils

cd ~/spacemit_robot
source build/envsetup.sh
lunch k1-muse-pipro-ai-cubpet
cd components/multimedia/audio
mm
cd ../../model_zoo/asr
mm
cd ~/spacemit_robot
export PATH="$PWD/output/staging/bin:$PATH"
```

编译完成后，`audio_demo`、`asr_file_demo`、`asr_stream_demo` 安装在 `output/staging/bin`。每次新开终端需要重新执行上面最后两行。

## 确认输入设备

```bash
audio_demo list
```

`audio_demo list` 分别列出输入和输出设备，后续命令中的 `--device`（`-d`）和 `-i` 均使用这里的**输入设备索引**。该索引由 PortAudio 枚举顺序决定，与 `arecord -l` 中的 `hw:X,Y` 编号不一定相同；插拔设备后请重新查看。

环形麦克风阵列（USB 接入）在 `audio_demo list` 中通常显示为一个多声道输入设备，请记录其索引和最大输入声道数。

## 录音

先录制多声道原始音频，确认各通道有信号（声道数按设备实际能力填写，例如 2、4、6）：

```bash
audio_demo record ring_raw.wav --duration 5 --rate 16000 --channels <N> --device <device_id>
```

如果只需要单声道语音输入，可直接按单声道录制 5 秒：

```bash
audio_demo record ring_mono.wav --duration 5 --rate 16000 --channels 1 --device <device_id>
```

部分阵列仅支持 48 kHz，此时把 `--rate` 改为 `48000`。

## 回放确认

```bash
audio_demo play ring_mono.wav -c 1 -d <output_device_id>
```

## 语音识别验证（可选）

`asr_stream_demo` 会把多声道输入混成单声道后送入 ASR，可用来验证阵列采集效果：

```bash
asr_stream_demo -i <device_id> -c <N> -t 30 -f 3
```

也可以对录制的文件做识别：

```bash
asr_file_demo ring_mono.wav
```

更多参数见 [4.1.1 ASR](../../04-AI与算法/4.1-语音/4.1.1-ASR.md)。

## 声源定位

基于多声道音频的声源定位（DOA）使用 SDK 的 audio_process 组件，见 [6.3.3 音频算法](6.3.3-音频算法.md)。使用串口输出角度的六麦阵列模块时，见 [5.5.8 声源定位](../../05-机器人开发/5.7-人机交互/5.7.8-声源定位.md)。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 指定声道数后打开设备失败 | `--channels` 超出设备能力，按 `audio_demo list` 或 `arecord --dump-hw-params` 显示的最大输入声道数调整。 |
| 识别效果差 | 先单独回放各通道确认信号；远场场景请靠近阵列说话或提高采集增益（`alsamixer`）。 |
| `audio_demo: command not found` | 未编译 audio 组件，或当前终端未把 `output/staging/bin` 加入 `PATH`。 |
