# 6.3.12 USB 麦克风使用说明

本节介绍如何使用 SDK 的 audio 组件和 Model Zoo ASR 组件，通过 USB 麦克风采集音频并进行语音识别。相关接口见 [4.1.1 ASR](../../04-AI与算法/4.1-语音/4.1.1-ASR.md)、[6.3.2 audio](6.3.2-audio.md)。

## 前置条件

1. 按 [6.3.10 麦克风硬件调试说明](6.3.10-麦克风硬件调试说明.md) 连接麦克风，并把当前用户加入 `audio` 组。
2. 按 [2.3 构建编译](../../02-快速入门/2.3-构建编译.md) 获取 SDK（`spacemit_robot`）并完成基础环境配置。以下命令以 SDK 位于 `~/spacemit_robot` 为例。

## 编译音频与 ASR 组件

本节使用 SDK 自带的 audio 组件（`components/multimedia/audio`）采集音频，并使用 Model Zoo 中的 ASR 组件（`components/model_zoo/asr`）进行语音识别。

```bash
sudo apt install portaudio19-dev libasound2-dev libsndfile1-dev \
    libsamplerate0-dev libfftw3-dev libcurl4-openssl-dev alsa-utils

cd ~/spacemit_robot
source build/envsetup.sh
lunch k1-muse-pipro-ai-cubpet
cd components/multimedia/audio
mm
cd ../../model_zoo/asr
mm
cd ~/spacemit_robot
export PATH="$PWD/output/staging/bin:$PATH"
```

编译完成后，`audio_demo`、`asr_file_demo`、`asr_stream_demo` 安装在 `output/staging/bin`。每次新开终端需要重新执行上面最后两行。

## 确认输入设备

```bash
audio_demo list
```

`audio_demo list` 分别列出输入和输出设备，后续命令中的 `--device`（`-d`）和 `-i` 均使用这里的**输入设备索引**。该索引由 PortAudio 枚举顺序决定，与 `arecord -l` 中的 `hw:X,Y` 编号不一定相同；插拔设备后请重新查看。

## 录音

USB 麦克风通常为单声道，常见支持 16 kHz 或 48 kHz。以下录制 4 秒单声道音频（`<device_id>` 替换为上一步查到的输入设备索引）：

```bash
audio_demo record record.wav --duration 4 --rate 16000 --channels 1 --device <device_id>
```

如果设备不支持 16 kHz，可先用 [6.3.10](6.3.10-麦克风硬件调试说明.md) 中的 `arecord --dump-hw-params` 查看支持的采样率，改为 `--rate 48000` 录制。

预期日志包含：

```text
Recording 4s to record.wav...
Opened: 16000Hz, 1 channels, int16
Saved ... bytes to record.wav
```

## 回放确认

```bash
audio_demo list            # 查看输出设备索引
audio_demo play record.wav -c 1 -d <output_device_id>
```

也可以使用 `aplay record.wav` 通过系统默认输出设备播放。

## 语音识别验证（可选）

录音正常后，可以直接用 Model Zoo 的 ASR 组件验证采集质量。

文件识别：

```bash
asr_file_demo record.wav
```

麦克风流式识别（单声道麦克风指定 `-c 1`）：

```bash
asr_stream_demo -i <device_id> -c 1 -t 30 -f 3
```

识别模型首次运行时会自动准备到 `~/.cache/models/asr/`。更多参数、Python 示例和 K1 上的配置说明见 [4.1.1 ASR](../../04-AI与算法/4.1-语音/4.1.1-ASR.md)。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| `audio_demo: command not found` | 未编译 audio 组件，或当前终端未执行 `export PATH="$PWD/output/staging/bin:$PATH"`。 |
| 打开设备失败 / `Invalid sample rate` | 采样率或声道数超出设备能力，按 `arecord --dump-hw-params` 结果调整 `--rate`、`--channels`。 |
| 录音全是静音 | 检查 `alsamixer` 中的采集音量与静音状态，确认 `--device` 选择的是输入设备索引。 |
| 权限不足 | 确认当前用户已加入 `audio` 组，并已重新登录。 |
