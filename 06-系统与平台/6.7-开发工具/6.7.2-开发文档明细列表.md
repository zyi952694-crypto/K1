# 6.7.2 开发文档明细列表

## Bianbu-Linux 开发指南

Bianbu Linux 是适配 Spacemit Stone 系列芯片的 BSP（Board Support Package）及 SDK，包含以下核心组件：

- 监管程序接口（OpenSBI）
- 引导加载程序（U-Boot / UEFI）
- Linux 内核
- 根文件系统（集成多种中间件与基础库）
- 示例程序与开发工具

其目标是为处理器提供完整的 Linux 支持，帮助开发者快速开展驱动开发与应用开发工作。

📘 文档入口：https://www.spacemit.com/community/document/info?lang=zh&nodepath=software/SDK/buildroot/k1_buildroot/index.md

### Bianbu 系列版本介绍

- **Bianbu**：
   基于 Ubuntu 社区源码构建，针对 RISC-V 架构进行深度优化，是其他固件版本的基础操作系统。支持：
  - Bianbu Minimal（命令行版本）
  - Bianbu Desktop（GNOME 桌面版本）
  - Bianbu Desktop Lite（LXQt 桌面版本）
- **Bianbu LXQt（原 Bianbu Star）**：
   提供轻量桌面环境。Bianbu 2.3 起，原 Bianbu Star 归入 Bianbu LXQt 产品线。
- **ROS2_LXQT**：
   基于 Bianbu 2.2 Desktop Lite（LXQt）做 rootfs 客制化，预装 ROS 2 与机器人开发套件（RDK/BRDK），并集成多媒体中间件（MediaEngine）、RVV 优化库（RVV-Opt Libs），构建机器人应用基础设施。也可以直接使用更轻量的 Bianbu 通用固件按需安装，客制化清单见 [2.2 镜像烧录](../../02-快速入门/2.2-镜像烧录/MUSE-Pi-Pro.md#ros2_lxqt-与-bianbu-通用固件)。
- **Bianbu NAS**：
   基于 Bianbu Minimal 精简优化，内置 OpenMediaVault Web 应用，专为 NAS 场景设计，支持二次开发与驱动适配。

ROS2_LXQT 的通用系统操作可参考 Bianbu 开发指南，预装软件与桌面客制化内容见上述固件说明。
