本仓库为实习生提供 K1 文档重构的工作框架。阅读 [K1 文档目录](index.md)，维护时参照 [迁移说明与任务清单](docs/重构说明.md)。

## 1. 章节安排

| 原 K1 章节 | 新框架 | 处理方式 |
| --- | --- | --- |
| 1. 快速开始 | 1. 快速开始 | 保留正文，统一目录命名、标题、索引和元数据形式。 |
| 2. ROS2_LXQT 基础使用 | 2. ROS2_LXQT 基础使用 | 保留正文和主题分类。 |

## 2. 内容状态

- 保留本仓库已有的 6 篇文档，其中 ASR、TTS、VAD、声纹、目标检测已归入新目录；这些既有 K1 适配内容优先于旧教程。
- 其余正文从固定版本的上游 K1 文档迁移，保留原有命令、代码、版本条件和 K1 专用用法。
- K3 有分类但尚无对应 K1 内容的页面标注“**K1 兼容性待确认**”，并链接固定版本的 K3 对应文档。占位页面不表示已经支持该功能。
- 本次交付是文档框架与迁移基线。后续同步 SDK 内容时，应先核对 K1 代码与依赖，再用最新的兼容内容覆盖；保留 K1 可运行而 K3 没有的部分。

本次未执行 K1/K3 SDK 构建或硬件测试；旧文档中的运行结果为来源文档内容，不是本次复测结果。

## 3. 文档检查

使用 Python 3.10 或更新版本：

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements-docs.txt
python3 scripts/check_docs.py
```

检查覆盖本地链接、图片、标题锚点、代码围栏、侧边栏元数据、重复 slug、导航可达性、迁移记录及 K3 第 4/5 节目录覆盖。验证记录见 [验收记录](docs/验收记录.md)。

仓库没有文档网站构建配置；Markdown 可直接在 GitHub 或编辑器中阅读。接入网站时按 [路由迁移表](docs/route-migrations.json) 配置重定向，该表本身不会自动创建网站重定向。
