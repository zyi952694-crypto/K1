# 3.1 WHEELTEC差速小车适配

## 案例简介

本案例展示了 K1 开发板适配轮趣科技教育版ROS差速小车的完整流程。一个完整的 ROS 机器人系统通常由四个核心部分组成：运动底盘（执行）、ROS 主控（决策）、传感器（感知）以及电池（能源）。其中，电池集成在运动底盘上，通过电气线路为机器人各个模块供电，运动底盘、ROS 主控与传感器之间也依靠电气线路进行数据通信与协同工作。本案例详细演示了如何将 K1 开发板作为 ROS 主控，与轮趣教育版差速小车对接，并实现对小车的运动控制。

## 硬件清单

- SpaceMit K1 开发板一块
- 轮趣科技教育版 ROS 差速小车一辆

## 环境适配

### 软件准备

先按 [ROS2 安装](../06-系统与平台/6.5-ROS2/6.5.1-ROS2安装.md) 配置 ROS 2 Humble。以下命令使用 Bash 终端执行。

安装底盘、雷达与键盘控制所需依赖：

```bash
sudo apt update
sudo apt install ros-dev-tools ros-humble-ros-base \
    ros-humble-turtlesim ros-humble-navigation2 \
    ros-humble-joint-state-publisher ros-humble-robot-state-publisher \
    ros-humble-robot-localization \
    ros-humble-teleop-twist-keyboard ros-humble-pcl-ros \
    ros-humble-diagnostic-updater libpcap0.8-dev libboost-thread-dev
```

下载本节使用的 [WHEELTEC 源码包](https://archive.spacemit.com/ros2/code/src_k1.tar.gz)，解压到工作空间：

```bash
mkdir -p ~/wheeltec_ws
cd ~/wheeltec_ws
wget https://archive.spacemit.com/ros2/code/src_k1.tar.gz
tar -xzf src_k1.tar.gz
source /opt/ros/humble/setup.bash
```

后续构建命令在 `~/wheeltec_ws` 执行。源码位于 `src/`，构建产物位于 `build/`、`install/` 和 `log/`。

### K1 开发板

**硬件信息**

使用开发板替换轮趣 ROS 小车原有的树莓派，作为 ROS 主控。

供电：使用运动底盘(STM32)控制器的TypeC-TypeC电源接口直接供电（5V）或使用电池直接供电（12V）。

信号：主控通过 USB 接口连接运动底盘、激光雷达和相机。

![](assets/SpaceMit_K1_1.png)

![](assets/SpaceMit_K1_2.png)

各传感器的连接和配置方法见下文。

### 运动底盘

**硬件信息**

轮趣教育版ROS差速小车的运动底盘为STM32的驱控一体控制板。

![](assets/wheeltec_controller.png)

供电：起源于电池，主要通过T头线或其它分流线输出到其它部件。

信号：主控向运动底盘发送指令，控制电机和轮子转动。

**适配方法**

连接运动底盘与主控的供电线（Type-C 至 Type-C），打开运动底盘开关，等待 Bianbu 系统启动。再连接信号线（Type-C 至 USB），在主控上打开终端，查看设备端口：
```shell
sudo dmesg | tail -20
```
查看类似于以下的输出，确认运动底盘USB设备端口号```/dev/ttyACM0```：
```shell
[ 1673.471036] usb 2-1.1: new full-speed USB device number 8 using xhci-hcd
[ 1673.675568] cdc_acm 2-1.1:1.0: ttyACM0: USB ACM device
```
根据自己实际的端口号，输入以下命令查看设备信息：
```shell
udevadm info -a -n /dev/ttyACM0
```
查看类似于以下的设备信息输出，确认设备的```ATTRS{serial}```：
```shell
ATTRS{product}=="USB Single Serial"
ATTRS{serial}=="0002"
ATTRS{serial}=="xhci-hcd.0.auto"
```
输入以下命令重映射运动底盘的udev规则，固定USB串口设备命名：
```shell
echo 'SUBSYSTEM=="tty", ATTRS{serial}=="0002", MODE:="0777",SYMLINK+="wheeltec_controller"' | sudo tee /etc/udev/rules.d/wheeltec_controller.rules
```
输入以下命令重启udev服务：
```shell
sudo udevadm control --reload-rules
sudo udevadm trigger
```

**测试运行**

本节使用差速底盘。在 `~/wheeltec_ws/src/turn_on_wheeltec_robot/launch/turn_on_wheeltec_robot.launch.py` 中，将 `minibot_type` 的 `launch_arguments` 改为：

```python
launch_arguments={'mini_diff': 'true'}.items(),
```

编译底盘节点、机器人模型、IMU 滤波组件及其依赖。源码包已包含 `ackermann_msgs`，保留 `package.xml` 中的依赖声明：
```bash
cd ~/wheeltec_ws
source /opt/ros/humble/setup.bash
colcon build --packages-up-to turn_on_wheeltec_robot wheeltec_robot_urdf imu_filter_madgwick
source install/setup.bash
ros2 launch turn_on_wheeltec_robot turn_on_wheeltec_robot.launch.py
```

打开另一个 Bash 终端，启动键盘控制节点：
```bash
source /opt/ros/humble/setup.bash
ros2 run teleop_twist_keyboard teleop_twist_keyboard
```

按终端显示的按键映射控制小车运动。

### 激光雷达

**硬件信息**

轮趣教育版ROS差速小车使用的是镭神智能的激光雷达，型号为M10P。

供电与信号：通过 USB 接口连接主控。

![](assets/wheeltec_lidar.png)

**适配方法**

使用数据线（Type-C 至 USB）连接激光雷达与主控。在主控上打开终端，查看设备端口：
```shell
sudo dmesg | tail -20
```
查看类似于以下的输出，确认激光雷达USB设备端口号```/dev/ttyACM1```：
```shell
[ 4562.938371] usb 2-1.3: new full-speed USB device number 9 using xhci-hcd
[ 4563.146987] cdc_acm 2-1.3:1.0: ttyACM1: USB ACM device
```
根据自己实际的端口号，输入以下命令查看设备信息：
```shell
udevadm info -a -n /dev/ttyACM1
```
查看类似于以下的设备信息输出，确认设备的```ATTRS{serial}```：
```shell
ATTRS{product}=="USB Single Serial"
ATTRS{serial}=="5A6D016420"
ATTRS{serial}=="xhci-hcd.0.auto"
```
输入以下命令重映射激光雷达的udev规则，固定USB串口设备命名：
```shell
echo 'SUBSYSTEM=="tty", ATTRS{serial}=="5A6D016420", MODE:="0777",SYMLINK+="wheeltec_lidar"' | sudo tee /etc/udev/rules.d/wheeltec_lidar.rules
```
输入以下命令重启udev服务：
```shell
sudo udevadm control --reload-rules
sudo udevadm trigger
```

**测试运行**

激光雷达驱动位于 `src/wheeltec_lidar_ros2/LSlidar/`，包名为 `lslidar_driver` 和 `lslidar_msgs`。编译驱动及其依赖：
```bash
cd ~/wheeltec_ws
source /opt/ros/humble/setup.bash
colcon build --packages-up-to lslidar_driver
source install/setup.bash
ros2 launch lslidar_driver lsm10p_uart_launch.py
```
在同网段的PC上可以通过rviz2观察激光雷达的实时数据。打开一个终端发布雷达静态坐标变换：
```shell
ros2 run tf2_ros static_transform_publisher 0 0 0 0 0 0 base_link laser
```
打开另一个终端：
```shell
ros2 run rviz2 rviz2
```
修改Fixed Frame 为laser，点击add -> by topic -> /scan ，点击ok。观察激光雷达数据如下所示：

![](assets/wheeltec_lidar_rviz.png)

### 相机

**硬件信息**

轮趣教育版ROS差速小车使用的是单目RGB相机，型号为C70。

供电与信号：通过 USB 接口连接主控。

![](assets/wheeltec_camera.png)

**适配方法**

使用 USB 数据线连接相机与主控。在主控上打开终端，查看设备端口：
```shell
v4l2-ctl --list-devices
```
查看类似于以下的输出，确认相机USB设备端口号```/dev/video20```：
```shell
Integrated Webcam: Integrated W (usb-xhci-hcd.0.auto-1.4):
	/dev/video20
	/dev/video21
	/dev/media1
```

**测试运行**

安装相机usb-cam包：
```shell
sudo apt install ros-humble-usb-cam
source /opt/ros/humble/setup.bash
ros2 run usb_cam usb_cam_node_exe --ros-args -p video_device:=/dev/video20
```
打开一个新终端，输入以下命令查看输出图像话题：
```shell
ros2 topic echo /image_raw
```
也可以在同网段的PC上输入以下命令，查看实时图像：
```shell
ros2 run rqt_image_view rqt_image_view
```
![](assets/wheeltec_camera_rviz.png)
