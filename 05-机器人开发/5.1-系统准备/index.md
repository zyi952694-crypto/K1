# 5.1 系统准备

先安装 ROS 2；使用 BROS 功能包时，再安装 AI Robot。已安装的环境可直接使用。

- [5.1.1 ROS2 安装](5.1.1-ROS2安装.md)
- [5.1.2 AI Robot 安装](5.1.2-AI-Robot安装.md)
- [5.1.3 ROS2_LXQT 桌面安装工具](5.1.3-ROS2_LXQT桌面安装工具.md)

按开发任务选择依赖安装方式：

| 开发任务 | 安装入口 |
| :--- | :--- |
| 编译 Robot SDK | 按 [2.4 构建编译](../../02-快速入门/2.4-构建编译.md)准备构建环境，按组件提示安装依赖 |
| 使用 ROS 2 | 按 [5.1.1 ROS2 安装](5.1.1-ROS2安装.md)启用软件源并安装所需功能包 |
| 使用 RDK | 先安装 ROS 2，再按 [5.1.2 AI Robot 安装](5.1.2-AI-Robot安装.md)准备 `/opt/bros` 运行环境 |
| Python 开发 | 按 [6.6.1 Python 使用](../../06-系统与平台/6.6-开发工具/6.6.1-Python-使用.md)安装虚拟环境工具和项目依赖 |
| C/C++ 开发 | 按 [6.6.2 C++ 使用指南](../../06-系统与平台/6.6-开发工具/6.6.2-C++-使用指南.md)安装编译器、构建工具和开发库 |

SDK 获取与构建见 [2.4 构建编译](../../02-快速入门/2.4-构建编译.md)。
