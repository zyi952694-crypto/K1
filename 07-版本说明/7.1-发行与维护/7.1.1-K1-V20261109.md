# 7.1.1 K1-V20261109

## 发布版本号

- **版本号**：`K1-V20261109`
- **发布日期**：2026-11-09
- **SDK 版本**：`spacemit_robot` manifest `main` 分支（`b378a32`，2026-11-05）
- **方案配置**：`target/k1-muse-pipro-minimal.json`、`target/k1-muse-pipro-ai-cubpet.json`
- **系统固件**：Bianbu 2.3.5，系统准备见 [2.2 镜像烧录](../../02-快速入门/2.2-镜像烧录/MUSE-Pi-Pro.md)和 [2.3 系统升级](../../02-快速入门/2.3-系统升级.md)。

## 更新内容

- **破坏性变更**：
  - 文档目录按 SDK 统一结构组织，页面地址（slug）相应变化。
  - 第 4 章 AI 示例使用 SDK Model Zoo；原 K1 的参考方案及外设文档保留各自配套工程。
- **功能与修复**：

| 模块或领域 | 说明 |
| --- | --- |
| 快速入门 | 提供硬件介绍、镜像烧录、系统升级、SDK 构建和示例运行流程 |
| AI 与算法 | 语音、视觉、LLM、VLM、Agent、强化学习基于 SDK Model Zoo |
| 机器人开发 | 感知、运动控制、定位导航、路径规划、媒体传输、基础传感器、人机交互 |
| 系统与平台 | 系统服务、外设与驱动、多媒体、高性能计算、ROS2、引脚与总线、开发工具、深度相机 |
| 开发配置 | 常用参数、配置副本和已知问题；[组件补丁](../../02-快速入门/2.10-SDK补丁.md)按功能单独应用 |

- **升级建议**：按 [2.4 构建编译](../../02-快速入门/2.4-构建编译.md) 获取 SDK；AI 示例参考 [4. AI 与算法](../../04-AI与算法/index.md)。
