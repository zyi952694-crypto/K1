# 7.1.1 K1-V20261109

> **状态**：草稿。标注“待确认”的字段需在正式发布前补全。

## 概括说明

本版本是首个基于 K3 SDK（`spacemit_robot`）的 K1 文档，用于替代旧版 K1 SDK 文档。面向使用 MUSE Pi Pro（SpacemiT K1）开发机器人应用的开发者。

- 尽量对齐 K3 SDK 文档，复用 K3 最新的模型和算法。
- K1 有、K3 没有的内容保留在对应章节中。
- 不修改 K3 SDK 源码，K1 与 K3 的配置和参数差异在文档中说明，见 [平台概览](../../01-平台概览.md)。

## 发布版本号

- **版本号**：`K1-V20261109`
- **发布或冻结日期**：待确认
- **SDK 版本**：`spacemit_robot` manifest `main` 分支（文档编写时 manifest 为 `b378a32`，2026-11-05）
- **K1 方案配置**：`target/k1-muse-pipro-minimal.json`、`target/k1-muse-pipro-ai-cubpet.json`
- **系统固件**：Bianbu 2.x 通用固件，或 ROS2_LXQT 定制固件，见 [2.2 镜像烧录](../../02-快速入门/2.2-镜像烧录.md)

## 更新内容

- **破坏性变更**：
  - 文档目录按 K3 SDK 文档结构重新组织，页面地址（slug）变化，旧书签需要更新。
  - 旧版 Demo Zoo（`spacemit-demo`）已移除，AI 示例统一改用 SDK Model Zoo。
- **功能与修复**：

| 模块或领域 | 说明 |
| --- | --- |
| 快速入门 | 2.1～2.4 与 K3 对齐，新增基于 K3 SDK 的构建编译和示例运行 |
| AI 与算法 | 语音、视觉、LLM、VLM、Agent、强化学习改用 SDK Model Zoo |
| 机器人开发 | 感知、控制、定位导航、路径规划、媒体传输、传感器按 K3 5.x 编号重组 |
| 系统与平台 | 6.1～6.5 与 K3 对齐；新增 6.6 ROS2、6.7 引脚与总线、6.8 开发工具、6.9 深度相机 |
| 平台差异 | 新增 K1 与 K3 差异说明，包含参数差异表和已知问题 |

- **升级建议**：从旧版 K1 文档迁移时，按 [2.3 构建编译](../../02-快速入门/2.3-构建编译.md) 重新获取 SDK；旧 Demo Zoo 示例改用 [4. AI 与算法](../../04-AI与算法/index.md) 中的对应示例。
