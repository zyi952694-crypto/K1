# 7.1.1 K1-V20261109

## 概括说明

本版本为基于 SpacemiT AI Robot SDK（`spacemit_robot`）的 K1 文档版本，面向使用 MUSE Pi Pro（SpacemiT K1）开发机器人应用的开发者。

- K1 与 K3 的配置和参数差异见 [平台概览](../../01-平台概览.md)。

## 发布版本号

- **版本号**：`K1-V20261109`
- **发布日期**：2026-11-09
- **SDK 版本**：`spacemit_robot` manifest `main` 分支（`b378a32`，2026-11-05）
- **K1 方案配置**：`target/k1-muse-pipro-minimal.json`、`target/k1-muse-pipro-ai-cubpet.json`
- **系统固件**：Bianbu 2.x 通用固件，或 ROS2_LXQT 定制固件，见 [2.2 镜像烧录](../../02-快速入门/2.2-镜像烧录.md)

## 更新内容

- **破坏性变更**：
  - 文档目录按 SDK 统一结构组织，页面地址（slug）相应变化。
  - AI 示例统一使用 SDK Model Zoo，不再包含 Demo Zoo（`spacemit-demo`）示例。
- **功能与修复**：

| 模块或领域 | 说明 |
| --- | --- |
| 快速入门 | 提供基于 SDK 的上电开机、镜像烧录、构建编译和示例运行流程 |
| AI 与算法 | 语音、视觉、LLM、VLM、Agent、强化学习基于 SDK Model Zoo |
| 机器人开发 | 感知、运动控制、定位导航、路径规划、媒体传输、基础传感器、人机交互 |
| 系统与平台 | 系统服务、外设与驱动、多媒体、高性能计算、ROS2、引脚与总线、开发工具、深度相机 |
| 平台差异 | K1 与 K3 差异说明，包含参数差异表和已知问题 |

- **升级建议**：按 [2.3 构建编译](../../02-快速入门/2.3-构建编译.md) 获取 SDK；AI 示例参考 [4. AI 与算法](../../04-AI与算法/index.md)。
