# 4.6 VLM

VLM（Vision Language Model，视觉语言模型）组件提供视觉语言模型的加载、推理与集成能力，支持图像描述、视觉问答等应用。组件通过 `llama-server` HTTP API 调用模型，默认使用 SpacemiT SMT 视觉后端，提供 C++ 接口和 Python HTTP 封装，支持单轮推理、带历史消息的对话及流式输出。

SDK 源码获取和基础编译环境配置统一参考 2.3-构建编译。后续命令在 K1 设备上执行，SDK 路径以 `/root/spacemit_robot` 为例。

**步骤1：安装依赖**

```bash
sudo apt-get update
sudo apt-get install -y build-essential cmake curl libyaml-cpp-dev nlohmann-json3-dev
sudo apt install llama.cpp-tools-spacemit

# Python 示例使用 PyYAML 读取配置
sudo apt install python3-yaml
```

Python 示例直接使用组件中的 `src/python/vlm.py`，无需另外构建 Python wheel。下面的 Python 命令使用系统 `python3`；若使用虚拟环境，需在该环境中安装 `pyyaml`。

**步骤2：下载模型**

```bash
cd /root/spacemit_robot/components/model_zoo/vlm

# 下载 FastVLM-MM 0.5B 模型
bash scripts/download_model.sh fastvlm-mm-0.5b-q4_1

# 下载脚本提供的四个模型，按需执行
for model in fastvlm-mm-0.5b-q4_1 Qwen3.5-0.8B Qwen3.5-2B Qwen3.5-4B; do
  bash scripts/download_model.sh "$model"
done

# 自定义存储目录，按需执行
VLM_CACHE_DIR=/data/models bash scripts/download_model.sh Qwen3.5-2B
```

模型默认下载到 `~/.cache/models/vlm/<model_name>/`，每个模型目录包含 `config.json`、文本 GGUF 文件和视觉 ONNX 文件，例如 FastVLM-MM 0.5B：

```text
~/.cache/models/vlm/fastvlm-mm-0.5b-q4_1/
├── config.json
├── fastvlm-text-0.5B-Q4_1.gguf
└── fastvlm_vision.f16.onnx
```

使用自定义存储目录时，需同步修改示例 YAML 的 `model_dir`；`VLM_CACHE_DIR` 仅影响下载位置，不会自动修改示例配置。模型缓存已存在且包含 `config.json` 时，下载脚本会跳过下载。

下载脚本提供的模型与标注大小如下。大小用于估算下载量，不代表模型解压大小或运行内存需求。

| 模型 | 下载脚本标注大小 | 说明 |
| --- | --- | --- |
| `fastvlm-mm-0.5b-q4_1` | 766M | 轻量级 VLM，基础及流式示例默认模型 |
| `Qwen3.5-0.8B` | 932M | Qwen3.5 视觉语言模型 |
| `Qwen3.5-2B` | 2.6G | Chat 示例默认模型 |
| `Qwen3.5-4B` | 3.9G | 按设备可用内存选择 |
| `qwen30ba3b-mm-q4_1` | 17.6G | 大参数量 MoE 模型，不作为本文 K1 入门示例 |

**步骤3：编译**

```bash
cd /root/spacemit_robot/components/model_zoo/vlm
mkdir -p build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
cmake --build . -j$(nproc)
ctest --output-on-failure
```

编译生成 `fastvlm_demo`、`chat_demo` 和 `stream_demo`。`ctest` 执行配置解析、模型工厂两项单元测试；模型推理通过下一步的示例验证。

**步骤4：运行示例**

K1 配备 4 个 X60 通用 CPU 核和 4 个 A60 智算核。本示例使用 SpaceMIT AI 加速后端，运行前需将示例配置中的 `generation.threads` 和 `generation.batch_threads` 从 `8` 改为 `4`，以匹配 K1 的智算核心数量。这两个参数分别控制文本模型的生成线程数和批量处理线程数。Python 与 C++ 共用 YAML 配置，修改后无需重新编译。`sed -i.bak` 会将修改前的配置保存为同名 `.bak` 文件。

```bash
cd /root/spacemit_robot/components/model_zoo/vlm

sed -i.bak -E \
  's/^([[:space:]]*(threads|batch_threads):)[[:space:]]*8[[:space:]]*$/\1 4/' \
  examples/fastvlm/config/fastvlm.yaml \
  examples/fastvlm/config/qwen3_5_0.8b.yaml \
  examples/fastvlm/config/qwen3_5_2b.yaml \
  examples/fastvlm/config/qwen3_5_4b.yaml
```

修改后的关键配置如下，以 FastVLM 为例；其他生成参数沿用原 YAML：

```yaml
backend: server
model_dir: ~/.cache/models/vlm/fastvlm-mm-0.5b-q4_1
media_backend: smt
cpu_affinity: 0-7
n_gpu_layers: 0
no_warmup: true
host: 127.0.0.1
port: 8093
generation:
  max_tokens: 150
  context_size: 4096
  top_k: 40
  top_p: 0.95
  temperature: 0.2
  repeat_penalty: 1.2
  threads: 4
  batch_threads: 4
  enable_thinking: false
  history_policy: last
```

将下文 `/path/to/image.jpg` 替换为设备上的实际图片路径。三个示例共用默认端口 `8093`，请依次运行；首次请求包含模型加载过程。示例在终端输出文本，不会打开图形窗口，也不生成带标注的结果图片。

C++ Demo（编译产物在 `build/` 目录）：

```bash
cd /root/spacemit_robot/components/model_zoo/vlm/build

# 基础图像描述
./fastvlm_demo \
  --config ../examples/fastvlm/config/fastvlm.yaml \
  --image /path/to/image.jpg \
  --prompt "用一句话描述这张图片"

# 多轮对话接口示例（Chat）
./chat_demo \
  --config ../examples/fastvlm/config/qwen3_5_2b.yaml \
  --image /path/to/image.jpg \
  --prompt "图片中有什么？"

# 流式输出
./stream_demo \
  --config ../examples/fastvlm/config/fastvlm.yaml \
  --image /path/to/image.jpg \
  --prompt "详细描述这张图片"
```

Python Demo：

```bash
cd /root/spacemit_robot/components/model_zoo/vlm

# 基础图像描述
python3 examples/fastvlm/python/vlm_demo.py \
  --config examples/fastvlm/config/fastvlm.yaml \
  --image /path/to/image.jpg \
  --prompt "Describe this image"

# 多轮对话接口示例（Chat）
python3 examples/fastvlm/python/chat_demo.py \
  --config examples/fastvlm/config/qwen3_5_2b.yaml \
  --image /path/to/image.jpg

# 流式输出
python3 examples/fastvlm/python/stream_demo.py \
  --config examples/fastvlm/config/fastvlm.yaml \
  --image /path/to/image.jpg
```

`chat_demo` 展示携带 system、user 消息的单次 Chat 请求，不会进入交互循环。集成多轮对话时，应用需维护消息列表，将上一轮 assistant 回复与新的 user 消息一并传入 Chat 接口。输出长度由 `generation.max_tokens` 控制。

> **说明**：配套视觉模型为 SpacemiT SMT ONNX 格式，组件默认使用 `server` 后端，通过 `llama-server --vision-backend smt` 加载视觉模型并启用硬件加速。示例正常结束时会回收自行启动的服务。手动中断后如有残留，应先确认对应 `llama-server` 的进程，再停止该进程；确认没有其他任务使用 TCM 后，可执行 `spacemit-tcm-smi -c` 释放残留资源。

VLM 也可通过 Gateway 以 OpenAI 兼容的 HTTP API 对外提供服务，详见 [SpacemiT AI SDK：Gateway 统一 HTTP/WS 接入层](https://www.spacemit.com/community/document/info?nodepath=ai/application_tools/ai-sdk.md&lang=zh&anchor=4-gateway-统一-httpws-接入层)。
